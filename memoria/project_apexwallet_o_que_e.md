O OpenIpWorld (IPAW / IPWALLET) é o portal onde o **cliente** da Apex acompanha os ativos de
propriedade intelectual dele. Ele existe para substituir dois fornecedores pagos:

| | o que faz | custo |
|---|---|---|
| **APOL** | cadastro de titulares e processos, cartas de despacho | R$ 2.030,21/mês (APEX IP) |
| **WEBSEEK** | base de marcas | R$ 735,52/mês (APEX MP) |

⚠️ **Os dois são VELA, o mesmo CNPJ.** Somados: **R$ 33.188,76/ano**, 25,06% do gasto anual de
software da casa. Isso muda a negociação: não são dois contratos independentes.

⛔ **O que o Webseek faz** que o Wallet ainda não faz é pergunta aberta do Gui — é metade do custo,
e sem a lista não dá para declarar o projeto pronto para desligar os dois.
